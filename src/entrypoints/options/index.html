Shortcuts for SoundCloud

Independent project, not affiliated with SoundCloud.

See what's playing without leaving your work

When a new track starts, a small now-playing card can slide into the corner of the page you are looking at, with the artwork, title, artist, and play, next and like buttons. It fades out on its own and never takes keyboard focus, so you can keep typing.

Drawing it into a page means the browser will ask you to allow the extension on all sites. It still only reads soundcloud.com; other pages are only used to show the card.

Keyboard shortcuts

Shortcuts are managed by your browser so they work from any tab.

Action Shortcut

Browsers allow four default shortcuts per extension. Unbound actions can be assigned on the shortcut settings page.
